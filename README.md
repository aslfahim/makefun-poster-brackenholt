BRACKENHOLT — a travel poster for a forest where the mushrooms grow taller
than the houses, and the best inn in the holt is a single cap. One Node
program paints it from raw pixels: an autumn dusk, distant trunks and
mushroom silhouettes, a giant spotted cap over a cream stem with a round
lamplit door and windows, neighbour mushrooms, a stone path, fireflies and
falling leaves. The holt's name is set in hand-drawn stroke letters in the
darkening sky. It writes one PNG to /output/entry.png.

## Run it

```sh
node main.ts
```
